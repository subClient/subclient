# Sub-Client
A free, non-commercial launcher for Minecraft: Java Edition.

Features: Microsoft sign-in, profiles, and installing mods, resource packs and shaders from Modrinth.

Game files are downloaded from Mojang's official servers.

The launcher contains no cheats and does not
sell anything. Sign-in data stays on the player's own PC.

Sub-Client is not affiliated with Mojang Studios or Microsoft. Minecraft is a trademark of Mojang Studios.
